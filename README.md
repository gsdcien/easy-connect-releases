# GSD Easy-Connect Agent

Desktop agent for connecting and managing your devices with [Octastat](https://octastat.com).

## Download

Download the latest version for your operating system from the [Releases](../../releases) page.

| Platform | Download |
|----------|----------|
| Windows 10/11 | [Download .exe](../../releases/latest/download/easy-connect-win.exe) |
| macOS 10.15+ | [Download .dmg](../../releases/latest/download/easy-connect-mac.dmg) |
| Linux (Ubuntu, Debian, Fedora) | [Download .tar.gz](../../releases/latest/download/easy-connect-linux.tar.gz) |

## Installation

### Windows
1. Download the `.exe` file
2. Run the installer
3. Follow the installation wizard

### macOS
1. Download the `.dmg` file
2. Open the DMG and drag Easy-Connect to Applications
3. Open Easy-Connect from Applications

### Linux
1. Download the `.tar.gz` file
2. Extract: `tar -xzf easy-connect-linux.tar.gz`
3. Run: `./easy-connect`

## Requirements

- Active Octastat account
- Internet connection for initial setup
- Local network access to your devices
